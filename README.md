# To-Do List Application

A simple desktop To-Do List application developed using Python, Tkinter, and SQLite.

## 📌 Project Description

This application helps users manage their daily tasks. Users can add new tasks, view their tasks, mark tasks as completed, and delete tasks. SQLite is used to store the task information.

## ✨ Features

- Add new tasks
- View existing tasks
- Mark tasks as completed
- Delete tasks
- Store tasks using SQLite database
- Simple and user-friendly graphical interface

## 🛠️ Technologies Used

- Python
- Tkinter
- SQLite
